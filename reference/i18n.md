# Translation lookup

The dashboard is available in Dutch and English. All user-facing text is
stored as translation keys (e.g. `"nav.clusters"`) rather than hardcoded
in R code, and
[`episodic_tr()`](https://certe-medical-epidemiology.github.io/EpiSODIC/reference/episodic_tr.md)
looks a key up in the requested language. A key that does not exist in
either language is shown as `[[key]]` rather than silently left blank,
so a missing translation is easy to spot.
